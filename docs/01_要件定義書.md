# 要件定義書

## 1. プロジェクト概要
- プロジェクト名：タスク管理アプリ
- 作成目的：
  - 設計〜開発〜テスト〜公開までの一連の流れを実践する
  - 自身の開発プロセス理解を深める
- 開発期間：2025/11/4 〜 2025/11/30

---

## 2. 背景
待機期間中なので、一貫した流れを体験してみたいと思ったため。CRUDまで行ったら認証等もやってみる。FWは今後変えてやってみる。

---

## 3. 利用者
| 利用者 | 目的 |
|--------|------|
| 一般ユーザー | 自身のタスクを管理する |
| 開発者（自分） | CRUD機能や設計〜テストを学ぶ |

---

## 4. 機能要件
| 機能名 | 内容 |
|--------|------|
| タスク一覧表示 | 登録されたタスクを一覧表示 |
| タスク登録 | 新しいタスクを追加 |
| タスク編集 | 既存のタスクの内容を更新 |
| タスク削除 | タスクを削除 |
| 完了状態管理 | タスクの完了/未完了を切り替え |

---

## 5. 非機能要件
| 分類 | 内容 |
|------|------|
| パフォーマンス | 一覧画面は1秒以内に表示 |
| セキュリティ | 不正入力対策（サニタイズ、バリデーション） |
| 操作性 | スマホ・PC両方で見やすいUI |
| 保守性 | コードは機能単位で分割し、コメントを明確にする |

---

## 6. 想定環境
| 項目 | 内容 |
|------|------|
| フロントエンド | Next.js + Tailwind CSS |
| バックエンド | Laravel |
| DB | MySQL / SQLite |
| デプロイ先 | 検討中 |
| ソース管理 | GitHub |
